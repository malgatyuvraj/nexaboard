# NexaBoard

NexaBoard is a modern SaaS dashboard built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- Landing page with SaaS-style hero and feature sections
- Dashboard page with 4 KPI cards:
  - Revenue
  - Users
  - Churn
  - Session time
- REST API endpoints:
  - `GET /api/health`
  - `GET /api/metrics`

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```
